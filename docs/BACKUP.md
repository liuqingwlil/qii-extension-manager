# 配置与清单 JSON 备份

本文介绍 JSON 配置与清单。需要备份实际扩展代码及本地扩展目录时，使用新增的 [Windows ZIP 文件迁移](MIGRATION.md)。JSON 和 ZIP 的导入、导出均成对排列。

小窗“工具”页和管理页“偏好设置”均有完整备份入口；扩展列表工具栏还提供快捷导出图标。

## 导出

点击“导出配置与清单 JSON”会重新读取浏览器的全部可见项目和最新管理器配置，再下载 JSON。搜索、分组、状态或收藏筛选不会限制导出范围。

完整备份为 `version: 2`、`kind: "extensions"`，包含扩展 ID、名称、启用状态、版本、类型、安装来源及可获得的来源链接，另保存来源浏览器和管理器 ID，以及分组、收藏、备注、场景、皮肤和偏好。版本指备份格式版本，扩展自身版本另存于清单中。

浏览器没有开放其他扩展安装包与私有数据的读取能力，因此此文件不含 CRX、密码、登录数据或其他扩展的内部设置。

## 导入并应用

1. 点击“导入 JSON 并应用”，选择导出的 JSON。
2. 查看预览中的要启用、要停用、已一致、未安装、受保护与需授权项目；此时不会改变浏览器状态。
3. 点击“确认导入并应用”。管理器合并配置，并恢复备份中已安装、可管理项目的启用状态；备份清单外项目的启停状态不变。
4. 等待实际浏览器状态核验，查看全部应用、部分应用或未完成结果。配置保存状态与扩展状态分别显示。
5. 若有缺失项目，可前往官方商店查找，或重新加载开发者模式扩展，然后点击“重新检查”。检查仅刷新预览，再点击“再次应用”才会继续恢复。

需要浏览器原生确认的操作仍由你完成。管理器自身、组织保护项、主题和新增权限待授权项不会被强行更改。未知来源仅提供官方名称搜索；开发者模式项目不会生成虚假的商店安装链接。不同商店的扩展 ID 可能不同，不会仅凭名称猜测对应关系。

恢复在当前管理页或小窗中执行，请等待完成再关闭。原生小窗失焦后可能自动收起；希望在恢复期间继续浏览时，可使用完整管理页。

## 恢复结果

结果逐项记录目标、操作前与核验时状态，区分已应用、已一致、未安装、受保护、需授权和未完成。只有配置保存成功且所有项目实际达到目标，才显示“备份已全部应用”。API 返回成功但实际状态未变、最终状态无法读取、配置保存失败均不会被隐藏。

可下载 JSON 恢复报告。上次报告单独保存在当前浏览器本地，小窗关闭重开或管理页切换后仍可展开查看。历史报告明确标注核验时间，不将其当作当前实时状态。若报告写入失败但恢复已完成，会提示下载本次结果，不会声称扩展操作被回滚。

## 兼容原配置备份

原 `version: 1` 配置备份仍可读取。通过“导入配置 → 合并导入”只恢复管理器配置，不改变扩展启停状态；通过“导入 JSON 并应用”入口则可明确应用其清单中保存的启用状态。

官方能力依据：[扩展管理 API](https://developer.chrome.com/docs/extensions/reference/api/management)、[Chrome 安装流程](https://developer.chrome.com/docs/extensions/how-to/distribute/install-extensions)。
