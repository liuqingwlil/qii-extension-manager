# 快捷小窗

把“栖”固定到 Chrome 或 Edge 工具栏后，点击图标即可打开原生小窗。也可以使用 `Alt+Shift+Q`。点击网页或浏览器其他区域，小窗由浏览器自动关闭；右上角关闭按钮也可随时收起。

小窗尺寸为 600 × 590 CSS 像素，使用内部滚动；完整管理页继续通过 `Alt+Shift+E` 或小窗入口打开。若系统缩放较大、屏幕可用空间较小，浏览器可能进一步限制小窗尺寸。

## 扩展

- 图标网格适合快速找到常用工具；列表适合查看名称和分组。
- 在 600×590 的可用空间下，普通网格可完整显示 15 项；点击搜索框右侧的“紧凑密度”可显示 6 列、24 项，保留名称、图标和独立开关。窄屏或批量选择时可显示的项目会减少。
- 顶部箭头可“收起顶部”，将人物区收为小条，继续增加列表空间。收起状态会在本浏览器中记住；再次点击即可展开。
- 使用搜索与状态、分组筛选，快速缩小结果范围。
- 用独立开关启停扩展；点击详情可查看权限、调整分组和个人备注、收藏或取消收藏。
- 批量模式可以选择多个结果，在预览后统一启用或停用，也可移动分组。
- 本管理器、组织策略和部分特殊类型受保护；需要重新授权的项目应单独启用。

开关处理中保留原手柄，成功反馈显示在固定页脚内并自动消失，不再挤动列表。失败信息保持可见，可关闭或重试；普通名称排序、全部筛选下保持原有滚动位置。选择“已启用 / 已停用”筛选或“启用优先”排序时，状态变化会相应更新结果位置。

## 场景

场景可以直接在小窗创建、编辑和删除。先勾选要管理的扩展，再用右侧状态按钮选择此场景要启用还是停用；未纳入管理范围的扩展保持原状。场景仅记录保存时的可管理项目，不会影响未来新安装的扩展。

应用场景前会显示变更预览，执行后反馈成功、跳过和失败项目。浏览器的原生确认仍需用户完成。

## 工具

“皮肤外观”可选择“森林序曲”或“爱莉希雅”。当前皮肤显示勾选和“使用中”，支持键盘方向键切换。皮肤会同步到完整管理页；浅色、深色与跟随系统的设置独立保留。

爱莉希雅皮肤在小窗顶部提供独立立绘区，配有花瓣、水晶和环形纹样。立绘裁切在页头范围，背景仅显示在卡片外部的空白区域；扩展卡片使用实色表面。装饰层不接收鼠标或触屏输入，也不会进入键盘焦点顺序。

可调整浅色、深色或跟随系统，以及小窗的网格 / 列表和密度偏好。小窗视图独立于完整管理页保存。

“导出扩展文件 ZIP / 导入扩展文件 ZIP”相邻排列，打开完整管理页，通过 Windows 迁移助手打包、解包真实扩展目录。长时间文件操作在完整页进行，避免原生小窗因文件选择而失焦收起。首次连接及新电脑迁移见 [文件迁移](MIGRATION.md)。

“导出配置与清单 JSON”保存全部清单、版本、来源、启用状态和管理器配置，不受当前筛选影响。“导入 JSON 并应用”先显示预览，确认后恢复已安装扩展的启用状态并核验结果。缺失项目可通过官方商店或本地目录安装，再重新检查与应用；不会静默安装。上次恢复记录和报告保存在本地。

原有“导出配置 / 导入配置”继续用于只迁移管理器配置，不改变扩展启用状态。ZIP 包含扩展代码，JSON 不包含代码；两者均不包含其他扩展的私有存储或登录状态。

## 键盘和关闭

- `Alt+Shift+Q`：打开工具栏小窗。
- `/`：在扩展页快速搜索。
- `Tab`、`Shift+Tab`：访问按钮、开关与表单。
- `Esc`：先关闭内部详情或确认面板；处于主界面时关闭小窗。

小窗关闭时，已明确保存的配置会保留。原生浏览器小窗不能在点击网页后继续保持打开；需要长时间整理时，可进入完整管理页。[Chrome 原生弹窗说明](https://developer.chrome.com/docs/extensions/develop/ui/add-popup)
