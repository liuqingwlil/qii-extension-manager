# 隐私说明

“栖 · 扩展管理器”使用浏览器提供的扩展管理 API 工作，配置保存在当前浏览器用户资料的本地存储中。

## 使用的信息

- 浏览器返回的扩展清单：名称、ID、描述、版本、图标、安装来源、启停状态、权限以及可用的设置页或主页地址。
- 你主动创建的管理配置：分组、收藏、备注、场景和外观偏好。
- 管理操作的活动记录及其结果，用于在界面回顾操作。

这些信息用于本地展示和管理，不上传到开发者服务器。

## 不收集的信息

项目没有分析统计、广告、账户或外部追踪服务；不读取浏览历史、Cookie、密码、网页正文或其他扩展的私有存储。基础权限为 `management` 与 `storage`，没有网站内容访问权限或浏览历史权限。1.4.0 增加可选的 `nativeMessaging`，仅在点击连接 Windows 本地迁移助手时请求。

扩展图标来自浏览器提供的扩展资源。项目不会向外部服务发送扩展清单或备注，也不会通过网络请求获取浏览记录。你主动点击扩展主页、商店等链接时，浏览器会打开对应网站，这些网站遵循各自的隐私政策。

## 本地保存与导出

配置与记录保存在 `chrome.storage.local` 中，不使用 `chrome.storage.sync` 云同步。Chrome 和 Edge、不同用户资料之间各自独立。

导出备份是你主动触发的本地文件操作。JSON 包含管理器配置和扩展清单，不包含扩展安装文件、其他扩展的内部数据或登录状态。扩展清单和备注可能透露个人习惯，请妥善保管。

“导入配置”不改变扩展启停状态。“导入 JSON 并应用”在预览后由你确认，随后改变已安装项目的启用状态并核验结果；两者都不会静默安装缺失扩展。清单还包含版本及可获得的来源链接，恢复报告会记录目标状态、实际结果和失败原因，并保存在本地。

Windows 助手启动时会读取默认 Chrome / Edge 资料中的扩展登记和管理器识别文件，以自动配置明确匹配的栖管理器；存在多个 ID 时由你选择，识别不到时保留手动连接。实际扩展代码及登记的本地扩展目录仅在你触发文件迁移时读取，生成本地 ZIP、校验记录与恢复报告。它不会备份整个用户资料，也不会读取 Cookie、密码或其他扩展的私有存储。代码目录内原有文件会一起进入文件包，应按其原本的数据性质保管。恢复只写新建目录，不写入浏览器原有资料或企业安装策略。

连接助手会在当前用户本地应用目录安装助手文件，并登记 Chrome / Edge 的 Native Messaging host；只允许你明确填入的管理器 ID 调用。通信通过本机进程标准输入输出，不启动网络服务，也不上传文件。卸载扩展不会自动删除独立助手、连接登记或已导出的 ZIP。

卸载本管理器将删除它在该浏览器用户资料中的本地存储；已经导出的备份文件不会随之删除。

## 演示模式

通过本地 HTTP 开发服务访问时，界面使用明确标识的示例数据。该模式没有管理真实扩展的能力。加载到浏览器后的真实模式若读取失败，会显示错误，不会用演示数据掩盖问题。
