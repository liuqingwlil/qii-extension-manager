# ImageGen 设计稿提示词

使用内置 ImageGen 生成两张设计稿。示例浏览器资料和目录均使用虚构数据。

## 主流程

```text
Use case: ui-mockup. Create ONE polished, high-resolution desktop design sheet for a real, Chinese-language Windows app named “栖 · 扩展文件迁移助手”. This is a redesigned user-owned app, native desktop, with a coherent quiet stationery-inspired appearance. Straight-on flat pixels with sharp readable Chinese text, no perspective, no monitor frame, no exterior caption. Layout: strictly 2 columns x 3 rows of separate windows, all six complete and equal sized, each within its own cell with a narrow light-gray gutter (~24 px) between. Large canvas nearly square or landscape 3:2. Each window has white/ivory #F7F8F4 body, white cards, subtle neutral #DEE5DF lines, charcoal pine #253F34 title text, muted #52655C caption, deep forest #285140 for primary buttons, flat surfaces, easily implementable in Tkinter. Pale sage hover/select with normal text, zero outlines/glows/side bars/triangles on selected rows. Windows title bars low key. Modern Microsoft YaHei-style sans; generous visual spacing. Authentic file-tool, not a marketing page. No excessive ornament.
Top left window home: small pine green brand mark, header “栖 · 扩展文件迁移助手”, inside main title “把扩展文件一起带走”, brief intro “备份或恢复 Chrome 与 Edge 的扩展文件”, two equal white action cards side by side, “导出扩展文件” and “导入扩展文件”, their visible buttons “导出 ZIP” and “导入 ZIP”, separate clean “管理器连接” section with connection status and buttons “自动连接管理器” and “手动填写扩展 ID”, small muted local-only version footer. Top right contains illustration in header beside the home title, a compact white folder holding a single pale pine leaf, with one muted sage paper tab, in hand-crafted cut-paper style; important that the entire illustration has the plain exact same solid #F7F8F4 background and is fully visible, physically separated from text with lots of padding so it can be cropped into a reusable bitmap. Middle left window “选择浏览器资料”, subtitle, modern white table with column headers “浏览器 / 资料 / 目录”, 3 rows Chrome / Edge, bottom “选择自定义资料目录”, “取消”, primary “使用所选资料”. Middle right window “核对扩展文件目录”, subtitle “Chrome · 默认资料 · 12 个扩展”, concise line and clean white table with column headers “扩展 / 文件状态 / 源目录或原因”, 4 rows, one missing item, a bottom detail strip showing the path for a selected row, “定位选中项的目录”, “取消”, primary “继续导出”. Bottom left window “连接管理器”, clean form with label “扩展 ID”, single field, hint, “取消”, primary “保存连接”. Bottom right a “扩展文件已完整备份” result dialog with the summary “12 项扩展 · 86 个代码文件”, copyable-looking file path field, and bottom “完成”. Maintain crisp editorial typography, tiny neutral rounded corners if any. Keep full six windows within image boundaries. No text outside the windows. Use generic fictional paths like C:\Users\Demo, not personal data.
```

## 辅助流程

```text
Use case ui-mockup. Draw a second high fidelity mockup design sheet for the same Windows desktop utility named “栖 · 扩展文件迁移助手”. Output exactly SIX independent panels on a fixed two-column three-row grid, with small gutters. Keep each window wholly contained in its grid cell. Consistent warm ivory #F7F8F4, white #FFFFFF panels, subtle gray sage #DEE5DF dividers, pine charcoal #263C33 headlines, muted #52655C subtext, forest green #285140 primary controls. Native Windows title bar, well-rendered Simplified Chinese, Microsoft YaHei typography, flat subtle styling, no effects on hovered/selected items other than slight gray sage background. Use fictional paths only. Top left: browser extension manager chooser with headings “选择扩展管理器”, “浏览器 / 浏览器资料 / 扩展 ID”, two rows, “取消” and “连接所选管理器”. Top right: directory mapping confirmation “确认目录对应关系”, clear compact dialog with extension name, ID and source directory in white copyable-looking values, “返回” and “使用此目录”. Middle left: progress screen “正在导出扩展文件”, subtle descriptive text “正在写入并校验 ZIP 文件”, simple thin horizontal sage progress indicator. Middle right: recover result “扩展文件已恢复”, subtitle “请按安装清单在浏览器中完成安装”, white details rows for “恢复目录” and “迁移报告”, “打开安装清单” and “完成”. Bottom left: neutral error notice “目录不匹配”, body “所选目录没有 manifest.json”, “返回”; tiny pale gold warning symbol optional only here. Bottom right: standalone offline document opened in browser “安装扩展清单”, main white content surface on ivory, summary line, one white bordered item “示例扩展 · 本地扩展”, exact steps to open extensions page and load unpacked, a copy directory button “复制目录路径”. Readable and calm authentic utility. No illustrations, no extra screen variants, no exterior titles, no mock monitors, no decorative numbered labels.
```
