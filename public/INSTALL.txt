栖 · 扩展管理器 1.4.3

Google Chrome 和 Microsoft Edge 共用同一个安装 ZIP。

1. 将安装 ZIP 解压到一个固定目录，不要直接加载 ZIP。
2. Chrome 地址栏输入 chrome://extensions
   Edge 地址栏输入 edge://extensions
3. 打开“开发者模式”或“开发人员模式”。
4. 点击“加载已解压的扩展”，选择直接包含 manifest.json 的目录。
   如果使用源码项目，请先 npm install、npm run build，再选择 dist 目录。
5. 固定工具栏里的“栖 · 扩展管理器”，点击图标即可使用。

完整管理页：点击小窗中的“完整管理”，或在“工具”页选择“打开完整管理页”。
快捷小窗：点击工具栏图标或 Alt+Shift+Q 打开，点击网页其他位置即关闭。
小窗也支持右上角关闭按钮；Esc 先关闭内部面板，再次 Esc 关闭小窗。
快捷键：Alt+Shift+E 打开管理页；Ctrl+K 搜索。
如果快捷键冲突，可在浏览器扩展快捷键设置中修改。

皮肤切换：小窗“工具”页或完整管理页“偏好设置”中选择“皮肤外观”。
提供“森林序曲”与“爱莉希雅”，均支持浅色、深色与跟随系统。
爱莉希雅小窗包含独立立绘展示区与花瓣、水晶背景，装饰不会接收点击。
小窗显示更多：点击搜索框右侧“紧凑密度”图标，600×590 下可完整显示24项；普通网格为15项。
点击顶部向上箭头可收起人物页头，收起状态会记住。窗口可用空间较小时可显示的数量会减少。
开关成功提示位于固定页脚并自动消失，不占列表空间；失败信息可关闭或重试。

扩展文件迁移（ZIP）
小窗“工具”或完整管理页“偏好设置”中，ZIP导出与导入按钮相邻排列。
下载并运行 QiiMigration.exe 1.1.1。升级时先退出旧版助手，再从管理页重新下载并运行。
助手会自动识别并配置已启用的栖管理器；多个候选时选择对应资料。识别不到时可手动填写扩展 ID。
首次在管理页点击“连接本地迁移助手”允许可选本地通信权限，此后页面会自动检测和重连并显示状态。
ZIP可备份实际商店扩展目录和本地扩展代码；新电脑连接助手后一次解包全部文件并校验。
文件恢复不是自动安装；Chrome/Edge首次安装确认仍需完成，恢复结果附带目录和安装清单。

配置与清单（JSON）
小窗“工具”页或管理页“偏好设置”中，点击“导出配置与清单 JSON”保存整个工具箱。
使用“导入 JSON 并应用”选择文件，查看预览后点击“确认导入并应用”。
功能会恢复已安装扩展的启用状态，并保存分组、收藏、备注、皮肤和场景。
应用后重新读取浏览器状态，显示全部应用、部分完成或未完成，并可下载报告。
缺失扩展需要通过商店或开发者模式自行安装，再点击“重新检查”并再次应用。
旧版“导入配置”仍只合并管理器配置，不改变扩展启停状态。

主要功能
搜索筛选、网格/列表、收藏、分组、备注、启用/停用、批量启停与移动分组、
场景保存和切换前预览、权限审阅、扩展选项与原生详情、原生确认卸载、
浅色/深色/跟随系统、配置 JSON 备份与合并导入、操作记录。

说明
每个浏览器、每个用户资料单独管理。组织策略和浏览器保护无法绕过。
主题等特殊项目可通过“浏览器详情”继续管理。
配置备份不包含 CRX 安装包、其他扩展内部设置、密码或登录数据。
“导入 JSON 并应用”仅在确认后改变备份中项目的启停状态，不会静默安装扩展。
普通 HTTP 页面仅展示明确标注的演示数据，真实管理必须安装此扩展。
仅使用 management 与 storage 权限，无网页内容访问权限，无外部遥测。
